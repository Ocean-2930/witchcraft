# Units Instructions

`units/`는 플레이어와 적이 공유하는 전투 상태, 능력치, 피해 계산 및 전투 결과를 담당한다.

## Model

- 장비와 무관한 기초 능력치는 `utilities.unit_base.UnitBase`, 런타임 전투 상태와 공통 전투 동작은 `Unit`에서 관리한다.
- `Player`, `Enemy`에는 해당 유닛 유형에만 필요한 상태와 동작만 둔다.
- 피해 계산 입력은 `DamageBlock`, 계산 결과와 미리보기 값은 전용 결과 객체로 전달한다.
- 확률 또는 무작위 계산은 테스트할 수 있도록 가능한 경우 외부에서 `Random` 인스턴스를 받을 수 있게 유지한다.

## Rules

- 체력, 마나, 확률, 속도처럼 범위 제한이 있는 값은 기존 상수와 clamp 규칙을 따른다.
- 전투 공식을 바꿀 때 실제 적용 경로와 미리보기 경로가 같은 규칙을 사용하는지 함께 확인한다.
- 아이템이나 스킬 타입을 외부에 편의상 재공개하기 전에 해당 타입의 실제 소유 package와 공개 API를 확인한다.

## Exports

- 외부 전투 로직에서 사용하는 유닛 및 결과 타입만 `units/__init__.py`와 `__all__`에 공개한다.
