# Character Motion Import

영상 가공과 게임 리소스 등록을 연결하는 프로젝트 전용 스킬이다. 사용자가 지정한 스킬 이름을 유지한다. 텍스트는 UTF-8로 읽고 쓴다.

## 책임과 입력

- 영상 가공 절차는 복제하지 않는다. 먼저 [vedio_to_motion_sheet](../vedio_to_motion_sheet/SKILL.md)를 읽고 그 스킬로 분석·추출·배경 제거·복원·시트 조립·검수의 1~6단계를 수행한다.
- 이 스킬은 이후 PNG 배치, 캐릭터 JSON 정렬, 필요한 기존 게임 경로 연결을 담당한다. 하위 가공 스킬의 게임 코드 변경 제한은 가공 단계의 경계이며, 사용자가 요청한 게임 등록은 이 단계에서 처리한다.
- 영상 경로, 캐릭터 코드, 모션 종류와 결과 파일명을 사용자 지시와 영상·기존 폴더에서 확인한다. 명확한 대상은 재확인하지 않는다. 식별이 불가능할 때만 누락 정보를 묻는다.
- 여러 영상은 각각 캐릭터와 모션에 매핑한다. 같은 캐릭터라고 근거 없이 가정하거나 기존 PNG를 한꺼번에 교체하지 않는다.

## 1. 현재 프로젝트 계약 확인

프로젝트 루트 기준으로 필요한 부분을 읽는다.

- `data/definitions/characters.json`: 캐릭터 코드 및 기존 `motions` 보정값.
- `units/character_definitions.py`: JSON 로더와 허용 필드·검증.
- `ui/dungeon_scene/textures.py`: 캐릭터별 실제 파일명과 텍스처 키 매핑.
- `ui/dungeon_scene/player_marker.py`: 재생, 배율, 기준점, 좌우 반전과 캐시.
- `docs/ui_flow.md`, `docs/skill_flow.md`, `docs/architecture.md`: 관련 동작과 책임.
- 스킬 동작 연결이 필요한 경우에만 `skills/skill_base.py`, 해당 구현체 및 `scenes/dungeon_scene.py`의 시전 흐름.

기존 구조를 우선 재사용한다. 새 캐릭터의 게임 지원까지 요청받지 않았다면 선택 화면·영웅·세이브 레지스트리에 새 캐릭터를 임의 등록하지 않는다.

## 2. 영상 가공과 PNG 등록

- 하위 스킬의 최신 규격을 적용한다. 현재 기본값은 512×512 프레임 8개, 가로 4096×512 RGBA, 빈 배경 alpha=0, 첫·마지막 동일, 접지 기준 y=448이다.
- 대기·걷기는 한 주기, 공격은 준비·공격·복귀가 빠지지 않는 구간을 선택한다. 짧은 타격 순간을 균등 추출로 놓치는 경우 핵심 시점을 선택하고 재생 타이밍의 한계를 기록한다.
- 최종 파일은 `assets/images/characters/{code}/{filename}.png`에 둔다. 파일명과 JSON의 모션 키를 구분한다. 현재 `idle`, `walk`, `attack`이 모션 키이며 발렌은 `stannding.png`·`walking.png`, 레네아는 `standing.png`·`walk.png`, 공격은 양쪽 모두 `attack.png`를 사용한다. 항상 현재 로더에서 다시 확인한다.
- 사용자가 파일명을 지정하면 따른다. 기존 매핑과 다르면 새 파일을 실제로 읽도록 관련 매핑만 변경하고 다른 모션 파일명을 일괄 정리하지 않는다.
- 교체 요청이 명확하면 해당 파일을 교체한다. 교체 요청이 없고 같은 파일이 존재하면 별도 이름으로 보존한다. 최종 매핑은 선택된 실제 파일과 일치시킨다.
- PNG는 로컬 리소스로 유지하고 Git에 강제로 추가하지 않는다. 최종 파일만 요청한 경우 미리보기·메타데이터·프레임 폴더를 최종 위치에 남기지 않는다.

## 3. IDLE을 기준으로 JSON 보정

`characters.json`에서 해당 캐릭터의 해당 `motions` 항목만 변경하고 이름·설명·다른 캐릭터·이미 보정된 모션은 보존한다.

```json
"attack": {
  "scale": 1.0,
  "anchor": [256, 448],
  "offset": [0, 0]
}
```

- 위 숫자는 기본 구조 예시이며 완성 보정값이 아니다. 현재 IDLE과 새 시트의 같은 자세를 비교해 실제 값을 측정한다.
- `scale`: 동일한 배율을 모션 전체에 적용한다. 머리·몸통 등 공통 신체의 크기를 우선 비교하고 검기·펼친 망토·치켜든 칼의 전체 바운딩 박스로 몸 크기를 추정하지 않는다. 매 프레임 자동 크기 맞춤은 사용하지 않는다.
- `anchor: [x,y]`: 원본 512×512 좌표에서 타일 발 위치에 놓을 기준점. x 증가 시 그림은 왼쪽으로, y 증가 시 위로 이동한다. 기존 IDLE이 y=448 규격과 다르면 실제 발 위치를 고려한다. 모션 키마다 무조건 [256,448]을 넣지 않는다.
- `offset: [x,y]`: 공통 추가 위치 보정. 양수는 오른쪽·아래쪽이며 원본 좌표 단위로 배율과 함께 확대된다.
- 모션 전환의 신체 중심과 접지 높이가 일치하도록 배율과 anchor를 먼저 조정한 뒤 offset을 미세 조정한다. 기존 IDLE이 없으면 임시 기준임을 밝히고 측정 가능한 기준을 사용한다.
- 공통 보정 이후에도 생성 프레임의 등록 위치가 흔들릴 때만 선택적 `frame_offsets`에 8개의 [x,y]를 지정한다. 첫·마지막 값은 같게 두며, 의도된 몸 숙임·점프·전진 동작은 제거하지 않는다.
- 좌우 반전 시 anchor와 가로 보정도 함께 반전되는 현재 렌더러를 사용한다. 원본 PNG에 같은 보정을 다시 구워 넣어 이중 적용하지 않는다.
- 확대된 효과를 원본 셀 경계로 잘라내지 않는다. 원본 이미지에서의 여백과 게임 화면에서의 배율 보정은 별개다.

## 4. 필요한 게임 연결만 추가

- 기존 모션이면 PNG와 JSON 및 필요한 파일 매핑만 갱신한다. 이미 구현된 스킬 필드·실행 루프를 다시 만들지 않는다.
- 새로운 단발 모션이면 실제 파일의 텍스처 키 `character_{motion}`와 재생 경로가 연결되는지 확인한다. JSON 항목만 추가하면 새 PNG가 자동 로드된다고 가정하지 않는다.
- 스킬에 연결하는 요청이면 해당 스킬 정의의 `motion`을 지정한다. `None`은 모션만 생략하며 스킬 효과는 실행한다. 성공한 시전에서 한 번 재생 후 IDLE 복귀, 실패·파일 누락 시 입력이 잠기지 않는 기존 동작을 유지한다.
- 시트에서 산출한 원본 FPS를 게임 전역 속도에 자동 덮어쓰지 않는다. 현재 공격은 8프레임 × 0.05초 = 0.4초 단발 재생이다. 반복 모션과 끝 자세가 중복되는 단발 모션의 재생 규칙을 구분한다.
- 모델·소유권·저장 대상이 바뀌는 경우 프로젝트 AGENTS.md에 따라 serializer·검증·호환성·회귀 테스트를 함께 갱신한다. PNG와 표시용 JSON 보정만 바뀌면 저장 버전을 올리지 않는다.

## 5. 검증과 전달

- 하위 스킬의 PNG 검수 결과를 확인한다. 이어서 IDLE→새 모션→IDLE의 몸 크기·가로 중심·발 위치를 같은 화면 좌표에서 비교한다. 좌우 방향 모두 확인한다.
- 단발 재생 종료, 재시전 시작 프레임, 재생 중 입력 차단과 누락 파일의 안전한 생략을 확인한다. 같은 자세의 정렬과 의도된 동작을 구분하며 완전히 동일한 그림이라고 주장하지 않는다.
- JSON은 UTF-8과 문법뿐 아니라 실제 `load_character_definitions()`로 검증한다. 보정값은 scene 생성 시 읽으므로 재진입·재시작이 필요하며 텍스처 캐시가 남는 실행 환경에서는 재시작으로 확인한다.
- 코드 변경 시 기본 compileall 검사를 실행하고 변경된 재생·정렬 경로를 테스트한다. 저장 관련 변경은 `tests/test_save_system.py` 회귀 검사를 실행한다. 코드 변경 없이 검증 결과가 충분하면 불필요한 테스트를 추가하지 않는다.
- 구조·UI·스킬 흐름이 달라졌으면 관련 docs를 함께 갱신한다. 상속 구조가 바뀌지 않으면 class_hierarchy를 불필요하게 수정하지 않는다.
- 최종 파일과 연결 검증을 마친 뒤 이번 작업의 임시 폴더만 정리한다. 원본 영상·사용자 파일·다른 캐릭터 리소스는 유지한다.
- 최종 응답은 PNG 경로, 조정한 캐릭터/모션 키, 핵심 보정값, 실제 수행한 검증과 남은 시각적 한계를 간단히 알린다. 사용자의 최종 PNG만 남기라는 요청을 우선한다.
